# Aster NFT Marketplace

Functional frontend prototype for an NFT marketplace. Built with React, TypeScript, Vite and Tailwind CSS v4.

## Run

```bash
npm install
npm run dev
```

## Included
- Marketplace/search
- NFT details
- Mock purchase flow
- Mock listing flow
- My NFTs
- Activity/legal placeholders

No blockchain, wallet transactions, real payments or backend are connected yet. The current data/state layer is intentionally mocked so integrations can be added next.
